# OSBot-AWS EC2: LLM Briefing Document

## Why OSBot-AWS EC2?

The native boto3 EC2 API is complex - hundreds of methods, inconsistent response formats, and verbose resource management. OSBot-AWS simplifies this dramatically:

**1. Simplified Instance Creation**
```python
# boto3 native - 30+ lines for instance with SSH access, key pairs, security groups...

# OSBot-AWS - one line for a fully configured instance
from osbot_aws.aws.ec2.utils.EC2__Create__Instance import EC2__Create__Instance

instance_id = EC2__Create__Instance().create_instance__with_amazon_linux__t3_nano__ssh_sg__spot()
```

**2. Ephemeral Instances with Context Manager**
```python
# Auto-creates instance, waits for SSH, deletes on exit
from osbot_aws.aws.ec2.utils.EC2__Temp__Instance import EC2__Temp__Instance

with EC2__Temp__Instance() as temp:
    result = temp.ssh().exec('uname -a')        # SSH ready to use
# Instance automatically terminated
```

**3. Clean Instance Details**
```python
# boto3 native - nested dicts, inconsistent keys, ResponseMetadata noise

# OSBot-AWS - clean, consistent structure
from osbot_aws.aws.ec2.EC2 import EC2

details = EC2().instance_details(instance_id)
# Returns: {'instance_id': '...', 'public_ip': '...', 'state': {...}, 'tags': [...], ...}
```

**4. Automatic Key Pair & Security Group Management**
```python
# Auto-creates key pair, saves to file with correct permissions
# Auto-creates security group with SSH access
create = EC2__Create__Instance()
create.key_name__create_if_doesnt_exist()       # Creates {account_id}__osbot__{region}.pem
create.security_group_with_ssh()                 # Creates SG allowing port 22
```

## Overview

| Class | Purpose |
|-------|---------|
| `EC2` | Core EC2 operations (instances, VPCs, subnets, security groups, key pairs) |
| `EC2_Instance` | High-level instance management helper |
| `AMI` | AMI lookup and management |
| `VPC` | VPC creation and management |
| `EC2__Create__Instance` | Simplified instance creation with auto-setup |
| `EC2__Temp__Instance` | Ephemeral instances via context manager |
| `EC2__Create__AMI` | Create custom AMIs from instances |
| `EC2__with_temp_role` | EC2 with auto-created temporary IAM role |

```python

    security_group_id = 'sg-0123456789abcdef0',
```

## EC2__Temp__Instance Class

Context manager for ephemeral instances - perfect for testing.

```python
from osbot_aws.aws.ec2.utils.EC2__Temp__Instance import EC2__Temp__Instance
```

### Basic Usage

```python
with EC2__Temp__Instance() as temp:
    # Instance is created and SSH is ready
    print(f"Instance ID: {temp.ec2_instance_id}")
    print(f"Public IP: {temp.ec2_instance.ip_address()}")
    
    # SSH access
    with temp.ssh() as ssh:
        result = ssh.exec('hostname')
        ssh.exec('df -h')

# Instance is automatically terminated on exit
```

### Configuration

```python
from osbot_aws.aws.ec2.EC2 import EC2

# Custom EC2 client (e.g., different region)
ec2 = EC2()

with EC2__Temp__Instance(ec2=ec2, wait_for_ssh=True) as temp:
    # Access the underlying objects
    create_instance = temp.ec2_create_instance      # EC2__Create__Instance
    ec2_instance = temp.ec2_instance                # EC2_Instance
    instance_id = temp.ec2_instance_id              # str
    
    # SSH with auto-configured key and user
    ssh = temp.ssh()                                # Uses ec2-user
```

### Skip SSH Wait

```python
# Don't wait for SSH (faster if you don't need it)
with EC2__Temp__Instance(wait_for_ssh=False) as temp:
    # Instance created but may not be SSH-ready yet
    temp.ec2_instance.wait_for_ssh()                # Manual wait if needed
```

## Using EC2 with Custom Credentials

### With Session Token (Temporary Credentials)

```python
import boto3
from osbot_aws.aws.ec2.EC2 import EC2
from osbot_utils.decorators.methods.cache_on_self import cache_on_self

class EC2__With_Boto3_Session(EC2):
    """EC2 class that uses a provided boto3.Session for credentials."""
    
    def __init__(self, boto3_session: boto3.Session):
        super().__init__()
        self._boto3_session = boto3_session
    
    @cache_on_self
    def client(self):
        return self._boto3_session.client('ec2')
    
    @cache_on_self
    def resource(self):
        return self._boto3_session.resource('ec2')

# Usage
session = boto3.Session(
    aws_access_key_id     = 'ASIAXXX...',
    aws_secret_access_key = 'xxx...',
    aws_session_token     = 'FwoGZXIvYXdzEBY...',
    region_name           = 'us-east-1'
)

ec2 = EC2__With_Boto3_Session(session)
instances = ec2.instances_details()
vpcs = ec2.vpcs()
```

## Complete Example: Create Instance with SSH Access

```python
from osbot_aws.aws.ec2.utils.EC2__Create__Instance import EC2__Create__Instance

    ssh.exec('pip3 install requests')
```

```python
from osbot_aws.aws.ec2.utils.EC2__Temp__Instance import EC2__Temp__Instance

def run_integration_tests():
    with EC2__Temp__Instance() as temp:
        print(f"Testing on: {temp.ec2_instance.ip_address()}")
        
        with temp.ssh() as ssh:
            # Install dependencies
            ssh.exec('sudo yum install -y python3-pip')
            ssh.exec('pip3 install pytest myapp')
            
            # Run tests
            result = ssh.exec('python3 -m pytest /path/to/tests')
            
            # Check result
            if 'FAILED' in result:
                raise Exception("Tests failed!")
        
        print("Tests passed!")
    # Instance automatically cleaned up

run_integration_tests()
```
