# OSBot-AWS Session & IAM: LLM Briefing Document

## Why OSBot-AWS Session & IAM?

Managing AWS credentials and IAM resources with boto3 is tedious and error-prone. OSBot-AWS provides:

**1. Simplified Client Creation**
```python
# boto3 native - verbose setup
import boto3
from botocore.config import Config

config = Config(retries={'max_attempts': 1, 'mode': 'standard'})
session = boto3.Session(profile_name='my-profile', region_name='us-east-1')
client = session.client('s3', config=config)

# OSBot-AWS - one line
from osbot_aws.apis.Session import Session
client = Session().client('s3')
```

**2. Automatic Credential Resolution**
```python
# Automatically checks: environment variables → AWS profiles → IAM roles
# No manual credential handling needed
session = Session()
credentials = session.credentials()         # Returns dict with access_key, secret_key, token
identity = session.caller_identity()        # Who am I?
```

**3. Temporary Role Management**
```python
# boto3 native - 50+ lines of role creation, policy attachment, assume role, credential refresh...

# OSBot-AWS - clean abstraction
from osbot_aws.aws.iam.IAM_Assume_Role import IAM_Assume_Role

with IAM_Assume_Role('my-temp-role', policies_to_add=[{'service': 's3', 'action': '*', 'resource': '*'}]) as role:
    role.create_role()
    s3_client = role.boto3_client('s3')     # Client with assumed role credentials
```

**4. Clear Error Messages**
```python
# boto3 native - cryptic ClientError exceptions

# OSBot-AWS - descriptive exceptions with guidance
# Session_No_Credentials: "No Security credentials were found. Please check..."
# Session_Bad_Credentials: "Current Security credentials are invalid! Please check..."
```

**5. Custom Credentials Support**
```python
# Easily create service classes with user-provided credentials (no env vars needed)
from osbot_aws.aws.session.Session__Kwargs__S3 import Session__Kwargs__S3
from osbot_aws.aws.s3.S3 import S3

s3_kwargs = Session__Kwargs__S3(
    aws_access_key_id     = 'user_provided_key',
    aws_secret_access_key = 'user_provided_secret',
    region_name           = 'eu-west-1'
)
s3 = S3(session_kwargs__s3=s3_kwargs)           # Uses provided credentials

# Note: For temporary credentials with session tokens, use IAM_Assume_Role
# or pass credentials directly to boto3 (see "Session Token Support" section)
```

## Overview

| Class | Purpose |
|-------|---------|
| **Session** | Core boto3 client/resource creation with automatic credential handling |
| **Session__Kwargs** | Type-safe configuration for custom credentials and endpoints |
| **IAM** | Core IAM operations (users, roles, policies, access keys) |
| **IAM_Role** | High-level role management |
| **IAM_Policy** | Policy creation and management |
| **IAM_User** | User management |
| **IAM_Assume_Role** | Temporary role creation and credential management |
| **Temp_Role__For_Service** | Mixin for services needing temporary elevated permissions |

**Key Capability:** All service classes (S3, Lambda, EC2, etc.) support custom credentials via `Session__Kwargs`, enabling multi-account access and user-provided credentials without environment variables.

## Session Class

The `Session` class is the foundation for all AWS service access in OSBot-AWS.

### Import and Basic Usage

```python
from osbot_aws.apis.Session import Session

session = Session()

# Create clients for any AWS service
s3_client     = session.client('s3')
lambda_client = session.client('lambda')
iam_client    = session.client('iam')

# Create resources (higher-level boto3 interface)
s3_resource = session.resource('s3')
```

### With Custom Configuration

```python
session = Session(
    region_name  = 'eu-west-1',
    profile_name = 'my-aws-profile',
    endpoint_url = 'http://localhost:4566'      # LocalStack
)
client = session.client('s3')
```

### Credential Information

```python
session = Session()

# Get current credentials
creds = session.credentials()
# Returns: {
#     'access_key': '...',
#     'secret_key': '...',
#     'token': '...',              # Session token (if using assumed role)
#     'method': 'env',             # How credentials were found
#     'profile': 'default'
# }

# Verify credentials work
is_valid = session.credentials_ok()             # True/False

# Get caller identity (who am I?)
identity = session.caller_identity()
# Returns: {
#     'UserId': '...',
#     'Account': '123456789012',
#     'Arn': 'arn:aws:iam::123456789012:user/my-user'
# }
```

### Profile Management

```python
session = Session()

# List available AWS profiles
profiles = session.profiles()                   # ['default', 'prod', 'dev', ...]

profile_map = session.profiles_map()            # Dict with full profile configuration
```

## Creating Service Classes with Custom Credentials

OSBot-AWS service classes (S3, Lambda, EC2, etc.) can be instantiated with user-provided credentials, bypassing environment variables entirely. This is essential for:

- Multi-account access
- Cross-account operations
- User-provided AWS credentials in web applications
- Testing with different credential sets

### Using Session__Kwargs with Custom Credentials

```python
from osbot_aws.aws.session.Session__Kwargs__S3 import Session__Kwargs__S3
from osbot_aws.aws.session.Session__Kwargs__Lambda import Session__Kwargs__Lambda
from osbot_aws.aws.s3.S3 import S3
from osbot_aws.aws.lambda_.Lambda import Lambda

# User-provided credentials
user_access_key = 'AKIAIOSFODNN7EXAMPLE'
user_secret_key = 'wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY'
user_region     = 'eu-west-1'

# Create S3 with custom credentials
s3_kwargs = Session__Kwargs__S3(
    aws_access_key_id     = user_access_key,
    aws_secret_access_key = user_secret_key,
    region_name           = user_region
)
s3 = S3(session_kwargs__s3=s3_kwargs)

# Now all S3 operations use the provided credentials
buckets = s3.buckets()
s3.file_create_from_string('hello world', 'my-bucket', 'test.txt')

# Create Lambda with custom credentials
lambda_kwargs = Session__Kwargs__Lambda(
    aws_access_key_id     = user_access_key,
    aws_secret_access_key = user_secret_key,
    region_name           = user_region
)
lambda_func = Lambda('my-function', session_kwargs__lambda=lambda_kwargs)
result = lambda_func.invoke({'test': 'data'})
```

### Using Session Directly with Custom Credentials

For services without dedicated `Session__Kwargs` classes, use the `Session` class directly:

```python
from osbot_aws.apis.Session import Session

# Create session with custom credentials
session = Session()
client = session.client(
    service_name          = 'ec2',
    aws_access_key_id     = user_access_key,
    aws_secret_access_key = user_secret_key,
    region_name           = user_region
)

# Use the client directly
instances = client.describe_instances()
```

```python
data = s3_account_a.file_contents('source-bucket', 'data.json')
```

### Session__Kwargs Base Class

All service-specific kwargs inherit from `Session__Kwargs`:

```python
from osbot_utils.type_safe.Type_Safe import Type_Safe

class Session__Kwargs(Type_Safe):
    aws_access_key_id       : str = None
    aws_secret_access_key   : str = None
    endpoint_url            : str = None
    region_name             : str = None

# Service-specific versions add service_name
class Session__Kwargs__S3(Session__Kwargs):
    service_name: str = 's3'

class Session__Kwargs__Lambda(Session__Kwargs):
    service_name: str = 'lambda'
```

### Session Token Support (Temporary Credentials)

AWS temporary credentials (from STS AssumeRole, federation, etc.) include three components:
- `AccessKeyId`
- `SecretAccessKey`  
- `SessionToken` (the temporary session token)

**Current Support:**

| Path | Session Token Support |
|------|----------------------|
| `IAM_Assume_Role.boto3_client()` | ✅ Full support (auto-managed) |
| `IAM_Assume_Role.boto3_resource()` | ✅ Full support (auto-managed) |
| `Session.botocore_session()` | ✅ Has `aws_session_token` parameter |
| `Session.client_boto3()` | ❌ Missing `aws_session_token` parameter |
| `Session__Kwargs` | ❌ Missing `aws_session_token` field |

**Using Temporary Credentials via IAM_Assume_Role (Recommended):**

```python
from osbot_aws.aws.iam.IAM_Assume_Role import IAM_Assume_Role

# IAM_Assume_Role handles session tokens automatically
role = IAM_Assume_Role('my-role', policies_to_add=[...])
role.create_role()

# These clients use temporary credentials with session token
s3_client = role.boto3_client('s3')
lambda_client = role.boto3_client('lambda', region_name='us-west-2')
ec2_resource = role.boto3_resource('ec2')
```

**Using User-Provided Session Tokens (Workaround):**

If you have your own temporary credentials (e.g., from external STS call or federation), use boto3 directly:

```python
import boto3

# User-provided temporary credentials
temp_access_key    = 'ASIAXXX...'
temp_secret_key    = 'xxx...'
temp_session_token = 'FwoGZXIvYXdzEBY...'  # The session token

# Create boto3 client directly with session token
s3_client = boto3.client(
    's3',
    aws_access_key_id     = temp_access_key,
    aws_secret_access_key = temp_secret_key,
    aws_session_token     = temp_session_token,
    region_name           = 'us-east-1'
)

# Or create a session first
session = boto3.Session(
    aws_access_key_id     = temp_access_key,
    aws_secret_access_key = temp_secret_key,
    aws_session_token     = temp_session_token,
    region_name           = 'us-east-1'
)
s3_client = session.client('s3')
lambda_client = session.client('lambda')
```

**Using OSBot-AWS Service Classes with Session Tokens:**

To use the full OSBot-AWS `S3`, `Lambda`, etc. classes with temporary credentials, create wrapper classes that override the `client()` method:

```python
import boto3
from osbot_aws.aws.s3.S3 import S3
from osbot_aws.aws.lambda_.Lambda import Lambda
from osbot_utils.decorators.methods.cache_on_self import cache_on_self

class S3__With_Boto3_Session(S3):
    """S3 class that uses a provided boto3.Session for credentials."""
    
    def __init__(self, boto3_session: boto3.Session):
        super().__init__()
        self._boto3_session = boto3_session
    
    @cache_on_self
    def client(self):
        return self._boto3_session.client('s3')


class Lambda__With_Boto3_Session(Lambda):
    """Lambda class that uses a provided boto3.Session for credentials."""
    
    def __init__(self, name: str, boto3_session: boto3.Session):
        super().__init__(name)
        self._boto3_session = boto3_session
    
    @cache_on_self
    def client(self):
        return self._boto3_session.client('lambda')
```

**Usage - Single Session for Multiple Services:**

```python
import boto3

# Create boto3 session once with temporary credentials
session = boto3.Session(
    aws_access_key_id     = 'ASIAXXX...',
    aws_secret_access_key = 'xxx...',
    aws_session_token     = 'FwoGZXIvYXdzEBY...',
    region_name           = 'us-east-1'
)

# Use with S3 - all S3 methods work!
s3 = S3__With_Boto3_Session(session)
buckets = s3.buckets()
s3.file_create_from_string('hello world', 'my-bucket', 'test.txt')
contents = s3.file_contents('my-bucket', 'test.txt')
exists = s3.file_exists('my-bucket', 'test.txt')

# Use same session with Lambda
lambda_func = Lambda__With_Boto3_Session('my-function', session)
result = lambda_func.invoke({'key': 'value'})
config = lambda_func.configuration()

# Use same session with any other service
ec2_client = session.client('ec2')
dynamo_client = session.client('dynamodb')
```

**Reusable Mixin Pattern:**

For a more DRY approach, create a mixin class:

```python
import boto3
from osbot_utils.decorators.methods.cache_on_self import cache_on_self

class With_Boto3_Session:
    """Mixin that provides client() from a boto3.Session."""
    _boto3_session  : boto3.Session
    _service_name   : str
    
    @cache_on_self
    def client(self):
        return self._boto3_session.client(self._service_name)


class S3__With_Boto3_Session(With_Boto3_Session, S3):
    _service_name = 's3'
    
    def __init__(self, boto3_session: boto3.Session):
        self._boto3_session = boto3_session
        super().__init__()


class Lambda__With_Boto3_Session(With_Boto3_Session, Lambda):
    _service_name = 'lambda'
    
    def __init__(self, name: str, boto3_session: boto3.Session):
        self._boto3_session = boto3_session
        super().__init__(name)


class EC2__With_Boto3_Session(With_Boto3_Session, EC2):
    _service_name = 'ec2'
    
    def __init__(self, boto3_session: boto3.Session):
        self._boto3_session = boto3_session
        super().__init__()
```

This pattern allows you to use all the rich functionality of OSBot-AWS service classes while using temporary credentials with session tokens.

**Feature Gap:** To fully support user-provided session tokens via `Session__Kwargs`, the following would need to be added:

```python
# Proposed enhancement to Session__Kwargs
class Session__Kwargs(Type_Safe):
    aws_access_key_id       : str = None
    aws_secret_access_key   : str = None
    aws_session_token       : str = None    # <-- Add this
    endpoint_url            : str = None
    region_name             : str = None
```

And `Session.client_boto3()` would need to accept and pass through `aws_session_token`.

### Session Exceptions

```python
from osbot_aws.exceptions.Session_No_Credentials import Session_No_Credentials
from osbot_aws.exceptions.Session_Bad_Credentials import Session_Bad_Credentials
from osbot_aws.exceptions.Session_Client_Creation_Fail import Session_Client_Creation_Fail

try:
    session = Session()
    client = session.client('s3')
except Session_No_Credentials:
    print("No AWS credentials found")
except Session_Bad_Credentials as e:
    print(f"Invalid credentials: {e.message}")
except Session_Client_Creation_Fail as e:
    print(f"Failed to create client: {e.message}")
```

## IAM Class

Core IAM operations for users, roles, policies, and access keys.

### Import and Initialization

```python
from osbot_aws.aws.iam.IAM import IAM

iam = IAM()                                     # General IAM operations
iam = IAM(user_name='my-user')                  # User-specific operations
iam = IAM(role_name='my-role')                  # Role-specific operations
```

### Account Information

```python
iam = IAM()

account_id = iam.account_id()                   # '123456789012'
region = iam.region()                           # 'us-east-1'
identity = iam.caller_identity()                # Current caller identity
```

### Role Operations

```python
iam = IAM(role_name='my-role')

# Check existence
exists = iam.role_exists()
not_exists = iam.role_not_exists()

# Get role info
info = iam.role_info()                          # Full role details
arn = iam.role_arn()                            # Role ARN
assume_policy = iam.role_assume_policy()        # Trust policy document

# Create role
assume_policy_doc = {
    'Version': '2012-10-17',
    'Statement': [{
        'Effect': 'Allow',
        'Principal': {'Service': 'lambda.amazonaws.com'},
        'Action': 'sts:AssumeRole'
    }]
}
iam.role_create(assume_policy_doc, skip_if_exists=True)

# Update assume policy
iam.role_assume_policy_update(new_policy_doc)

# Delete role (auto-detaches policies)
iam.role_delete()
```

### Role Policy Management

```python
iam = IAM(role_name='my-role')

# Attach managed policy
iam.role_policy_attach('arn:aws:iam::aws:policy/AmazonS3ReadOnlyAccess')

# Attach multiple policies
iam.role_policies_attach([policy_arn_1, policy_arn_2])

# Add inline policy
policy_doc = {
    'Version': '2012-10-17',
    'Statement': [{'Effect': 'Allow', 'Action': 's3:*', 'Resource': '*'}]
}
iam.role_policy_add('my-inline-policy', policy_doc)

# List attached policies
policies = iam.role_policies_attached()         # Dict: {policy_name: policy_arn}
inline = iam.role_policies_inline()             # Inline policies

# Get all policy statements
statements = iam.role_policies_statements()
statements_list = iam.role_policies_statements(just_statements=True)  # Flat list

# Detach policy
iam.role_policy_detach(policy_arn)
iam.role_policies_detach([arn1, arn2])

# Delete inline policy
iam.policy_inline_delete('my-inline-policy')
```

### Policy Operations

```python
iam = IAM()

# Create policy
policy_doc = {
    'Version': '2012-10-17',
    'Statement': [{'Effect': 'Allow', 'Action': 's3:GetObject', 'Resource': '*'}]
}
result = iam.policy_create('my-policy', policy_doc)
# Returns: {'status': 'ok', 'policy_name': '...', 'policy_arn': '...', 'data': {...}}

# Get policy ARN from name
arn = iam.policy_arn('my-policy')               # arn:aws:iam::123456789012:policy/my-policy
arn = iam.policy_arn('my-policy', policy_path='/custom/')

# Check existence
exists = iam.policy_exists(policy_arn)
exists = iam.policy_exists_by_name('my-policy')

# Get policy details
info = iam.policy_info(policy_arn)
details = iam.policy_details(policy_arn)        # Includes policy document
statement = iam.policy_statement(policy_arn)    # Just the statement

# Update policy (creates new version)
iam.policy_create_version('my-policy', new_policy_doc)

# Delete policy
iam.policy_delete(policy_arn)
iam.policy_delete_by_name('my-policy')

# List all policies
all_policies = iam.policies()
by_name = iam.policies(index_by='PolicyName')
```

```python
iam = IAM(user_name='my-user')
```

```python
iam = IAM(user_name='my-user')
```

## IAM_Role Class

High-level role management with simplified creation patterns.

```python
from osbot_aws.aws.iam.IAM_Role import IAM_Role

role = IAM_Role('my-role')
# Or auto-generate name:
role = IAM_Role()                               # Creates 'osbot_temp_role_<random>'
```

### Create Role for Services

```python
role = IAM_Role('lambda-execution-role')

# Create for Lambda (auto-adds CloudWatch policy)
result = role.create_for__lambda()

# Create for CodeBuild
result = role.create_for__code_build()

# Create for any service
result = role.create_for_service__assume_role('ecs-tasks.amazonaws.com')
```

### Create with Custom Policy

```python
role = IAM_Role('my-role')

# From assume policy document
assume_doc = {
    'Version': '2012-10-17',
    'Statement': [{
        'Effect': 'Allow',
        'Principal': {'Service': 'lambda.amazonaws.com'},
        'Action': 'sts:AssumeRole'
    }]
}
result = role.create(assume_policy_document=assume_doc)
# Returns: {'status': 'ok', 'data': {...}, 'message': '...'}

# From statement
statement = {
    'Effect': 'Allow',
    'Principal': {'Service': 'ec2.amazonaws.com'},
    'Action': 'sts:AssumeRole'
}
result = role.create_from_statement(statement)
```

### Attach Policies

```python
role = IAM_Role('my-role')

# Attach policy (creates if needed)
policy_doc = {'Version': '2012-10-17', 'Statement': [...]}
policy_arn = role.attach_policy('my-policy', policy_doc)

# Get attached policies
for policy in role.policies():
    print(policy.policy_name, policy.statements)

# Get policy statements
statements = role.policies_statements()
```

### Instance Profile (for EC2)

```python
role = IAM_Role('ec2-role')
role.create_for_service__assume_role('ec2.amazonaws.com')

# Create instance profile
```

## Complete Example: Secure Cross-Account Access

```python
from osbot_aws.aws.iam.IAM_Assume_Role import IAM_Assume_Role
from osbot_aws.aws.s3.S3 import S3

def process_data_with_temp_permissions():
    # Define minimal required permissions
    policies = [
        {'service': 's3', 'action': 'GetObject', 'resource': 'arn:aws:s3:::source-bucket/*'},
        {'service': 's3', 'action': 'PutObject', 'resource': 'arn:aws:s3:::dest-bucket/*'},
    ]
    
    # Create temporary role
    with IAM_Assume_Role('data-processor-role', policies_to_add=policies) as role:
        role.create_role()
        
        # Wait for role to be usable
        role.wait_for_valid_execution('s3', 'list_buckets')
        
        # Get S3 client with limited permissions
        s3_client = role.boto3_client('s3')
        
        # Process data
        response = s3_client.get_object(Bucket='source-bucket', Key='data.json')
        data = response['Body'].read()
        
        s3_client.put_object(Bucket='dest-bucket', Key='processed.json', Body=data)
        
        print("Data processed successfully")

# Run
process_data_with_temp_permissions()
```
